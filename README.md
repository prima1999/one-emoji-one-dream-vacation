One emoji, one dream vacation: a sunrise breaking over the sea — the first morning of the trip of your dreams, no words needed. The program writes exactly that one emoji to `/output/entry.txt`, and a judge picks the entry that most makes a stranger want to book the flight.

## Run it

```sh
node main.ts
```
